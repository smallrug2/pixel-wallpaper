## What it does
Draws retro pixel wallpapers (chevron / flag / bands / progress-bar modes) at low res and upscales clean.


## Requirements
Python 3.8+ and Pillow: pip install Pillow


## How to run
    python pixel_wallpaper.py --help
    python pixel_wallpaper.py --mode chevron --w 1920 --h 1080 --out wp.png


## Platform
Windows + Linux + Mac: yes.
